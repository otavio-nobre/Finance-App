# Finance-App 📈

A modern, native Android application designed for personal expense tracking, financial management, and projected investment returns calculation. Built using **Kotlin** and **Jetpack Compose**.

---

##  Key Features

-  **Income & Expense Tracking:** Log and categorize daily financial transactions effortlessly.
-  **Investment Projections:** Calculate estimated monthly yields and returns based on customized rate parameters.
-  **Modern UI/UX:** Clean, intuitive interface built with Jetpack Compose and Material Design 3 guidelines.
-  **Reactive State Management:** Seamless state handling to update real-time calculations.

---

## 🛠️ Tech Stack & Architecture

* **Language:** [Kotlin](https://kotlinlang.org/)
* **UI Toolkit:** [Jetpack Compose](https://developer.android.com/jetpack/compose)
* **Design System:** Material Design 3
* **Architecture Pattern:** MVVM (Model-View-ViewModel) / Clean Architecture
* **Navigation:** Jetpack Navigation Compose
* **Build System:** Gradle (Kotlin DSL)

---

* **Android Studio** (Ladybug / Jellyfish or newer recommended)
